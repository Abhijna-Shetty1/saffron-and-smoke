# Saffron & Smoke 🍽️

Saffron & Smoke is a restaurant website I built around a Rajasthani-inspired dining concept.

I wanted the design to feel warm, colourful and a little royal without making it look like a typical "luxury restaurant" template. The idea was to mix traditional Indian details with a clean, modern layout.

## Live website
https://saffron-and-smoke.onrender.com/

## What I built

- Responsive restaurant website
- Rajasthani-inspired menu
- Veg, Non-Veg, Drinks and Desserts menu categories
- Swipeable menu on mobile
- Restaurant gallery
- Chef / restaurant story section
- Table reservation form
- SQLite database for reservations
- Simple admin page to view reservations
- Responsive layout for desktop and mobile
- Small hover and scroll interactions

## Built with

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
